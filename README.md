# Continuous-Compliance-Alerting-with-AWS-Config-SNS-
# Overview

Monitor S3 buckets for public access and receive real-time alerts using AWS Config and SNS. This project demonstrates continuous compliance monitoring in AWS.

Objectives

Detect when an S3 bucket becomes public

Send instant email alerts via SNS

Document the alert workflow and capture screenshots

# Setup

S3 Bucket – Create a bucket and keep it private initially.

AWS Config – Enable monitoring for S3 bucket public access.

SNS Topic – Subscribe your email to receive alerts.

Trigger Alert – Make the bucket public to test alerting.

Capture Screenshot – Document the email alert for reference.

# Tools

AWS Config

Amazon SNS

AWS S3

Email for notifications
